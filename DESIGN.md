# SpeedReader design

Native Android, Operate / Read. The approved direction is a quiet personal reading desk: one word dominates the reader; title and author dominate the library. The shell uses warm paper (#F7F6F3), charcoal ink (#252922), muted olive (#62685D), fine rules (#DCDDD5) and restrained forest (#426650). Filled primary actions use ink with white text; secondary buttons use paper with ink text and a rule border. Screens are flat, with no ornamental imagery or custom button elevation. No shipping raster assets are used.

UI typography uses bundled Manrope with Cyrillic: regular text at variable weight 450, buttons at 550 and section headings at 600. The variable font is app/src/main/res/font/manrope.ttf; ui_regular.xml selects its 450 instance. The Manrope Project source is https://github.com/googlefonts/manrope; its SIL Open Font License is included in app/src/main/assets/Manrope-OFL.txt and docs/licenses/Manrope-OFL.txt. Native serif distinguishes 28sp screen headings, the 21sp reader book title and 22sp library titles. Body labels use 16sp, buttons and status use 14sp, library authors use 15sp and metadata uses 12sp. Reading remains independently configurable: 42sp serif by default, with an 18–72sp preference range. Each word is measured at the preferred size and reduced proportionally only when it overflows the available width, with no fixed minimum size. The preferred size is applied anew for the next word; fitting never changes the stored preference. Serif, sans serif, monospace and condensed reading faces remain available. All user-facing UI text has English and Russian equivalents.

Outer padding is 20dp plus system insets. Buttons and radio choices retain a 48dp minimum target; buttons have 6dp corners, fields and the reading stage have 8dp corners. Fields use a white fill, rule border, muted hint and 52dp minimum height. Native ripples and focus feedback communicate interaction. Words, seeking and repeated speed actions update immediately without added animation. The explicit Material Light shell remains independent of the ten reading palettes. System status icons are dark; navigation uses paper with dark icons in system day mode on Android API 27+, and light icons over an ink backdrop drawn beneath the actual bottom or side navigation insets in system night mode or on API 26. The content surface stays paper; navigation protection preserves content padding and updates on rendering, insets, resume, window focus and configuration changes. In compact reader layouts, the fixed outer ScrollView hosts system insets and navigation protection, so that protection stays in place while reading content scrolls.

A 48dp outlined icon-only Rotate screen button sits beside Open FB2 and Library, with a 24dp authored native vector, localized content description and tooltip. It pauses reading and saves position, then switches between sensor portrait and sensor landscape independently of system auto-rotate. Orientation is not persisted; the reading-font preference is unchanged. The word stage spans the full reading width. A row beneath it retains +1/−1 buttons around an underlined forest speed value with a 48dp minimum target. Tapping the value pauses reading, opens Appearance and scrolls to Reading speed at the bottom. Its 64dp-wide, 320dp-high vertical native SeekBar uses centered endpoint labels, with 500 at the top and 30 at the bottom, in whole-word-per-minute increments. The forest thumb and active track sit on a rule-colored inactive track; native accessibility range and keyboard control are retained. Position seeking remains horizontal; both position and word-size Material sliders use forest/rule colors without tick marks. The reading area fills available height, or becomes a scrollable 420dp area below 600dp screen height or above 1.5 font scale. Transport normally places Back 10, Read/Pause and Forward 10 together; above 1.15 font scale or below 360dp screen width, the step actions share a row above a full-width 52dp Read/Pause button.

Appearance groups language, word preview, typography, reading themes, custom colors and reading speed in a scrolling native screen. Ten theme previews form two columns, with 64dp minimum tile height and a stronger forest border plus localized text for the selected theme. Paper remains the default reading palette; Night, Sepia, Ink, Forest, Ocean, Plum, Sand, Slate and High contrast remain available. Reading palette values are defined in Themes.java and are separate from the shell palette. Custom colors affect the stage and preview; they require at least 4.5:1 contrast, including the 14sp reading-status text.

The library is a full native screen with a serif top bar, ink-filled Scan phone / Stop scan action, Found files / Books switch, secondary folder actions, search field and flat ListView separated by fine rules. Rows lead with embedded title and author, followed by available series/language/word count/progress and genre; missing authors use a localized fallback. Metadata is never invented. Folder access uses Android's document-tree picker. Live scan totals and Stop scan share the screen; unavailable or corrupt files are summarized without interrupting the scan. Below 500dp screen height, folder actions and Found files / Books move into More, help copy is omitted and status uses two lines to preserve visible rows. The system Back gesture returns to reading and stops an active scan, preserving imported books. Search uses a muted olive hint; counts use Books: / Книг: labels. Folder-access recovery appears first in folder-scan status; phone scans summarize protected or unavailable folders. Completed scan results retain structured counts and are formatted again in the current interface language when the library renders.

Found FB2 reuses the flat library list with 22sp serif titles (falling back to filename), optional 15sp authors, an explicit muted 14sp filename when it differs from the title, and muted 12sp paths. Paths stay on one line with middle ellipsis; unimportable files show a localized tap-to-retry label. Rows open the cached book or retry the original file; search matches title, author or path. The persistent found-file list keeps distinct source paths while cached books deduplicate by content. Scan phone optionally opens Android all-files access settings on API 30+ or requests legacy read-storage permission on older Android; folder scanning and individual import remain available without that grant.
